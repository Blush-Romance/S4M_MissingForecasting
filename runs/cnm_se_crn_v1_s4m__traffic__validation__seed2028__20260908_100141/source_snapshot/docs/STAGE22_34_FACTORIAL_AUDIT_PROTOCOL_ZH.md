# Step 22.34 主线证据审计与验证集四格对照

冻结日期：2026-09-07。PSAVS已按Step22.33科学门停止，本步骤不延续PSAVS或预算策略。

## 22.34.1 已有证据与缺口

已有Weather三seed正结果属于L5双视图版本；严格等实际缺失率多尺度版本在Weather有两seed验证证据，在Traffic有三seed验证/测试证据。不同版本不能混成同一最终模型的跨数据集证据。ETTh1与Electricity的完整组合为负结果，必须保留。PG95在Traffic也不是三seed都优于S4M。

既有Traffic汇总报告展示S4M、PG95、PG95+多尺度三组，不能单凭它确认PG95是多尺度收益的必要前提。已有S4M多尺度**test**评估工件不用于本步骤模型选择；本步骤补缺失的S4M多尺度**validation**对照，不重新评估test，也不打开test逐样本缓存。

历史报告仅作证据盘点，不能用未汇报的测试子结果决定新结构。PG95为关闭内容/掩码因子分解的MIPP分支，保留配对掩码干预、不变性损失和0.95稳定写入门；其内部贡献尚不能从一个整体开关完全区分。

## 22.34.2 唯一新增实验

Traffic固定seed集合2026/2027/2028；先seed2027短评估smoke（冒烟），再完整评估，随后补2026/2028。每个来源均为已有正式S4M checkpoint（检查点），不重新训练、不更新参数或记忆。

新增操作仅将同一冻结多尺度评估器应用到S4M验证集来源。batch size（批大小）16、输入192、预测96、862变量、8层512维、归一化与缺失资产全部继承原正式来源；新增缺失比例0.15，L1/L5/L20逐样本严格等移除计数，主融合权重0.5/0.25/0.25。L1仅为既有评估器的审计路，不计入三路部署成本。

`r0.06`为沿用的生成器标称参数，不等于实际缺失率；三个Traffic固定资产的实际缺失率约26%。正式配置同时保存nominal（标称）与realized（实际）值，不能将本实验表述为“实际仅缺失6%”。新评估可能在不同GPU运行，仅比较准确率；跨GPU历史耗时不用于声称加速。

相对现有S4M测试评估模板：split从test改为val；variant显式改为stage22_34_traffic_s4m_validation；正式max_eval_batches仍为-1。这是新验证实验ID，不覆盖旧结果。smoke独立配置只评估3批、计时热身1批；正式热身10批，完整1648窗口。只评估，不存在新增反向传播/optimizer步骤；源checkpoint须能加载、前向、评估并写入指标。

## 22.34.3 同资产四格分析

每seed比较：A=S4M，B=PG95，C=S4M+固定多尺度，D=PG95+固定多尺度。

- 先核验两边样本索引、完整目标计数、history/L1/L5/L20掩码逐位一致；源checkpoint身份正确；A/B分别与原正式训练的validation指标回算一致。
- 报告PG95单独收益A−B、多尺度在S4M上的收益A−C、多尺度在PG95上的收益B−D、PG95在多尺度下的增量C−D。
- 交互量=(B−D)−(A−C)，正值表示在该指标上PG95增强了多尺度的绝对减误差效果；这不是统计显著或因果证明。
- 逐seed及三seed均值/样本标准差全部保留，不按seed挑选模型。三seed训练随机性和缺失资产一起变化，不能拆称独立的两种稳健性证据。
- “PG95在集成下的稳定增量得到支持”仅在C→D三个seed均MSE/MAE严格改善时成立；否则记PG95_ROLE_NOT_CONSISTENT。另单独报告交互正负，不将主效应等同于协同。
- 这是当前开发协议的归因检查，不授权任何新test、训练结构、阈值或融合权重搜索；任何下一版模型都须新冻结协议。

## 22.34.4 工程与资源

复用已有UUID动态调度、原子GPU锁、非阻塞轮询、失败分类和OOM退避机制。共4个任务：seed2027 smoke→seed2027 formal→seed2026/2028 formal；后两项可按资源并行。最大并发3。

同类Traffic评估历史reserved峰值3932MiB。调度初值由旧6144MiB固定保守预留改为4608MiB（历史峰值+至少15%且不少于512MiB余量，向上取整到256MiB），仅改变启动估计，不改实验配置。正式根据smoke和历史峰值的较大值重新估计；发生OOM后不允许降低重试估计。资源不足等待，不牺牲正式协议。

共享runner只增加默认不生效的S4M-validation分支，保留所有旧分支行为；重新跑旧协议与新负例测试。所有新项目级脚本和配置在启动前做快照/哈希，关联到run目录。检查点来源、最终配置、GPU UUID、实际峰值、状态、退出码、逐样本缓存及自动报告全部保存。

本轮既不是论文写作，也不宣称二区水平；目标是决定后续该补贡献验证还是重建研究假设。
