## 22.42.2 固定分析规则

1. 每seed共1648窗口，主要路径固定为原始单路径`on`，既有多尺度`multiscale`只作次要对照；不得因次要指标好而替换主门。
2. 解码`history_mask_packed`：192位、bitorder='big'（高位先解码）、1为观测0为缺失；必须核对维度、样本索引、源评估row-shared（各变量共享时间掩码）检查，以及两模型10类资产逐项一致。
3. 按时间顺序等分四段；缺失率档沿用历史诊断固定[0,0.2)、[0.2,0.3)、[0.3,1]；末端连续缺失及最长缺失段固定0、1–5、6–20、>20；保留空组。分段数或边界不随结果变化。
4. 报告全局、四段、缺失档、末端缺失档、最长段档及时间×缺失率交叉分组。每组使用平方/绝对误差和除目标元素数，不将窗口指标无权平均冒充主指标。绝对变化=修复−原始；变化百分比为负代表改善。
5. 原始主路径时间四段的误差增量必须加和回全局；同时记录正/负窗口和最坏5%窗口对正误差增量的份额，不删除窗口，不以重叠窗口当独立seed。
6. 固定四个掩码描述量：历史缺失比例、末端连续缺失长度、最长缺失段、缺失段数；报告与逐窗口误差增量的Spearman（秩相关）描述，恒定或无变异时写NA，不做显著性/因果承诺。
7. 六checkpoint（模型检查点）审计：中心数、驻留样本数、银行计数字段分别记录；根据topM100/topK20标记实际检索分支；代表向量有限性、成对余弦和中心化有效秩必须同时注明数量上限。参数变化的相对二范数仅是训练状态差异，不叫梯度或因果效应。
8. 从训练日志保留全部实际epoch的train/observed-validation loss（训练/观测目标验证损失）与最佳epoch；明确内部选模只评分观测目标、按batch（批次）平均，主报告评分完整目标、按元素汇总。不能将二者的差值直接称为“缺失目标误差”。
