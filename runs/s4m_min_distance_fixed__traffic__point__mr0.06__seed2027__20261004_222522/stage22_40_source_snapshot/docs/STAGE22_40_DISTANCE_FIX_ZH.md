# 步骤22.40：只修正最小距离标准化

目标：验证最小距离分支错误引用已标准化最大距离的问题，是否实际损害预测。此轮属于基线错误修复（bug fix），不作为论文研究创新。

修改只允许 `fix_min_distance_normalization` 开关控制最小距离的标准化输入；默认关闭保留旧行为。不改最大距离、标准差稳定项、衰减公式、编码器、极值定位、损失或任何训练超参数。

## 公平对照

复用步骤22.36原S4M的Traffic、seed2027训练与固定共同随机数验证（CRN，Common Random Numbers）。完整变量数862，输入192，预测96，batch size（每批样本数）16，Adam优化器，学习率0.001，最多15 epochs（轮次），patience（早停等待轮数）3，原调度和checkpoint（模型存档）选择规则不变。原模型实际早停4轮；修复模型按相同规则可能在不同轮次停止，必须报告真实计算代价。

原始训练：`runs/s4m_paired_rng__traffic__point__mr0.06__seed2027__20260908_144251`。

原始固定验证：`runs/cnm_se_crn_v1_s4m__traffic__validation__seed2027__20260908_151505`。

主要比较取 `complete_target_mse_on` / `complete_target_mae_on`，即原始单路径MSE（均方误差）和MAE（平均绝对误差）。不取评估顶层的CNM（反事实嵌套掩码）多尺度集成指标，也不混用训练后普通验证指标。旧评估器固有的L1/L5/L20及CNM路线原封保留，只作次要记录，不新增机制，不访问test（测试集）。

正式训练开始前必须通过：旧版本与默认关闭前向恒等、参数初始化SHA256摘要恒等、随机流检查、模型开关检查、CPU（中央处理器）单元测试与队列假任务测试。随后GPU（图形处理器）完整架构、1轮2批训练的小规模检查分别覆盖关闭与开启，保存模型、重载并用同一CRN评估。所有四个训练/评估检查成功后才允许正式训练。

## 队列与资源

队列顺序：关闭训练检查 → 开启训练检查 → 关闭重载评估 → 开启重载评估 → 开启正式训练 → 开启正式固定验证。正式训练明确依赖全部四个检查。最大并发3，但本轮依赖串行：保护完整训练的历史显存峰值，并避免既有评估器同秒实验ID碰撞。

训练首轮准入6144MiB，评估4608MiB，符合更新的全局准入要求。原训练reserved（预留显存）峰值11870MiB，只记录风险，不拿13GiB默认门槛阻塞首轮尝试。OOM（显存不足）后沿用共用队列递增估计、退避、更多空闲资源/更大GPU后再试，永不降低已学习的需求，不改batch或模型预算。只清理自己的进程，不占用无用显存。

原入口尚不支持完整优化器/RNG（随机数生成器）断点续训；OOM只能从头重排，不可把最佳模型加载伪装成完整恢复。磁盘不足1GiB时明确停止，不删除任何数据或模型。
